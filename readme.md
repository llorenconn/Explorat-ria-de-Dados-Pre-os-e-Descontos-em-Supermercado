# 📊 Análise Exploratória de Dados — Supermercado

Projeto de análise exploratória de dados (EDA) utilizando Python e Pandas, com foco em preços, descontos e categorias de produtos de supermercado.

---

## 🚀 Objetivo

Explorar um dataset de produtos de supermercado para entender:

- Produtos mais caros
- Categorias com maiores preços médios
- Relação entre preços e descontos
- Distribuição dos dados

---

## 🛠️ Tecnologias utilizadas

- Python 3
- Pandas
- Matplotlib
